一键安装 BeMan

$ wget --https-only --max-redirect=0 -O install.sh https://beman.teadan.com/install.sh && bash install.sh

复制命令到 Linux 终端执行。安装器自动检测并安装缺失依赖，需要已有 wget、root 或 sudo 权限。首次安装 OpenSSH 可能启动 SSH 服务，BeMan 不会自动开启防护。

BeMan 能做什么？

专注 SSH 安全管理，不引入多余的复杂性。

SSH 安全防护

通过 OpenSSH 限制登录用户与来源 IP，强制公钥认证。

白名单管理

独立增删用户名与 IP，修改后自动保存。

自动升级

在工具箱中手动检查更新，发现新版立即升级，启动无需联网检测版本。

安全回滚

新规则需从新 SSH 会话确认，未确认时尝试自动回滚。

日志管理

支持 SSH 与 BeMan 审计脱敏统计、原始日志查看及只读容量检查。

安全卸载

撤销自身防护规则，卸载 BeMan，保留系统 SSH 和软件依赖。

一个命令，打开工具箱

无需 Web 管理后台。直接在 Linux 终端中管理防护状态和白名单。

  1. 01运行 beman，进入管理菜单。
  2. 02设置允许登录的用户和 IP。
  3. 03启动防护，并在新的 SSH 会话中确认。

保持简单，守住边界

不接管系统 SSH

不改变 SSH 监听端口，不自动开启防护，不删除系统依赖。

保留恢复通道
